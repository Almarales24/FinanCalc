# FinanCalc - Calculadora Financiera

Una aplicación web moderna para cálculos financieros construida con Angular 21 y TailwindCSS.

## 🚀 Características

- Calculadora de préstamos
- Interfaz responsiva y moderna
- Desarrollo rápido con Angular CLI
- Estilos con TailwindCSS

## 📋 Requisitos

- Node.js 18+
- npm 11+

## 🔧 Instalación

```bash
# Instalar dependencias
npm install
```

## 💻 Desarrollo

```bash
# Inicia el servidor de desarrollo
npm start
```

Abre tu navegador en `http://localhost:4200/`. La aplicación se recargará automáticamente cuando modifiques archivos fuente.

## 📦 Build

```bash
# Compilar para producción
npm run build
```

Los artefactos se almacenarán en el directorio `dist/`.

## 🧪 Tests

```bash
# Ejecutar pruebas unitarias con Vitest
npm test
```

## 📁 Estructura del Proyecto

```
src/
├── app/
│   ├── components/          # Componentes reutilizables
│   ├── models/              # Interfaces y tipos TypeScript
│   ├── services/            # Servicios de la aplicación
│   ├── app.ts              # Componente principal
│   ├── app.routes.ts       # Rutas de la aplicación
│   └── app.config.ts       # Configuración
├── assets/                  # Imágenes, iconos, etc.
├── styles.css              # Estilos globales
├── index.html              # Página principal
└── main.ts                 # Punto de entrada
```
